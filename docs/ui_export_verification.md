## 六类导出与数值一致性

最终每个标准场景生成 PDF、Markdown、HTML、Excel、Manifest、ZIP，顺序与 UI 下载顺序一致。产物只放本地忽略目录 `.tmp_tests/ui_exports/`，没有提交或上传。

- `verification.json`：生成时运行号、场景实际表规模、各文件大小、实验结果。
- `artifact_readback.json`：PDF 页数/SHA-256、ZIP 条目与独立文件逐字节一致、Excel 工作表/公式单元格检查、HTML 资源内嵌次数。
- `transaction.*`、`content.*`、`live.*`：同一次运行绑定的六类产物。

内容实验按用户 `user_id` 统计，实验组与对照组独立样本量各 6,000。连续型用户完播率用 Welch t-test；两组均值分别为 `0.5683954406137294` 和 `0.5396165962665143`；绝对差 `0.028778844347215116`，即 `2.8778844347215116` 个百分点；相对提升 `5.333202230311199%`；p-value `1.4098989398539446e-25`；95% 绝对差区间 `[0.023394925759012024, 0.03416276293541821]`，即约 `[2.33949, 3.41628]` 个百分点。

Excel 读回与结构化结果的 p-value、绝对/相对提升及区间端点逐项数值比较通过。PDF/HTML/Markdown 使用同一展示函数，p-value 保留科学计数法。显著性不直接等同上线建议，方法限制保留。

默认 Excel 不再生成 `Summary/Findings/Reviewer/Mapping/Manifest` 等重复英文 sheet；旧客户端可显式使用兼容模式。原有兼容测试调整为显式传参，同时新增默认不重复测试，没有删除失败测试。

## PDF 视觉验收与边界

使用 bundled Poppler `pdftoppm` 渲染全部页面为 1100 像素长边 PNG；用 `pypdf` 读回中文章节、版本、每页页码及实验数字。最终页数和哈希见附记与 `artifact_readback.json`。

视觉检查包括全部页面的联络图，另对三场景首页与实验统计区放大阅读，检查中文、长句换行、表格列宽、跨页表头、页脚及文字裁切。宽表每五列为一组，明确各组行顺序一致，不缩为不可读的整页宽表。报告不是把 Markdown 原文塞进一页；实际统计来源于结果协议与结果表。

第一次修复孤立表标题时发现 keepWithNext 导致整张表提前换页和大量空白，已改为节前最小剩余空间检查，让长表正常分行跨页，并重新渲染验收。

默认 `STSong-Light` CID 字体不随源码分发字体文件。Poppler 本机报告找不到该字体并使用 `SimSun` 替代，同时有 Symbol/ArialUnicode display-font 警告；实际中文渲染已目视确认。CID 字体依赖阅读器的 CJK 字体支持，本次不声称在全部 PDF 阅读器或所有操作系统上验过。没有使用未获授权的字体嵌入或字体下载。

PDF 默认不渲染静态 Plotly 图片；可视化保存在单文件离线 HTML。三个 HTML 各只内嵌一份 Plotly JS，未引用在线 CDN。原始输入源文件、完整数据库连接、密码与密钥不进入报告包。

## 限制与兼容说明

PDF 每张结果表最多 40 行、最多 20 张表、单元格文字最多 500 字符；有截断说明。Excel/CSV 每表最多 100,000 行，CSV 最多 20 表；超限写出明确提示。公式形态字符串在 CSV/Excel 中输出为文本，负数等数值保持数值类型。Excel 单元格超长文本显式截断。

Manifest 是安全配置摘要，不恢复原始数据；已脱敏的筛选值要求重新输入。界面缓存只用于固定模拟数据；上传内容留在会话内存。直播场次、观看会话、观测去重观众使用不同统计单位，界面和结果限制均说明，不把 54,000 会话当 54,000 场直播。

此子任务未初始化工作副本 Git，未执行 add、commit、tag、push，未改原始 clone 或远程。完整恢复来源、版本关系、打包/快照/全量测试以主任务迁移和验收文档为准。
