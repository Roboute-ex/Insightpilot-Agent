# 确定性分析引擎

## 定位

InsightPilot Agent v0.6 是本地确定性数据分析工作流。它不训练模型，不下载模型，不接入在线语言模型，也不要求 API key。结果质量主要取决于数据结构、字段映射、指标定义、统计函数、分析规则、证据链和结果呈现。

本次发布前完善解决的是分析引擎与产品呈现问题：内置模拟数据不够丰富、自动工作流缺少统一结果协议、结果表输出不稳定、分析方案与实际结果混在一起。增加模型参数不能替代这些工程能力。

## 组件职责

### Planner

Planner 根据用户问题和 Analysis Goal Mode 生成结构化 AnalysisPlan。它描述准备使用的指标、基准、维度、数据表和步骤，但不代表实际计算已经发生。

### Playbook

Playbook 声明字段要求、参数、只读查询模板、执行器、图表类型和输出章节。它适合重复、口径明确的分析任务，不能绕过 Column Mapping 或 SQL Safety。

### Analysis Engine

Analysis Engine 执行多基准指标对比、异常检测、漏斗顺序分解、维度贡献、实验比较和证据规则。所有 legacy 自动工作流都会适配为 AnalysisResultPackage，并返回非空结构化结果表。

### Reviewer

Reviewer 检查目标、计划、指标、结果、路由、限制、数据来源、映射、查询安全和导出边界。Reviewer 状态不能替代证据本身，它负责提示结果是否具备解释条件。

## 分析方案与分析结果

分析方案回答“准备怎么分析”：

- 使用哪些指标和数据表。
- 采用哪些基准和维度。
- 经过哪些确定性步骤。
- 是否需要只读计划审批。

分析结果回答“数据实际算出了什么”：

- 当前值、基准值、相对变化和标准分。
- 异常区间和异常等级。
- 漏斗各阶段的估算影响。
- 维度负向与正向贡献。
- 可追溯 evidence 和引用这些 evidence 的建议。

预览分析方案不会执行实际计算。开始分析后才会生成 AnalysisResultPackage、结果表、图表、结论和建议。

## 核心计算

指标诊断同时计算目标日与前 7 日均值、前 28 日均值、上周同日，以及近 7 日与前一个 7 日均值。标准分使用历史日分布估算，并保留样本量和完整性说明。

交易漏斗使用确定性顺序替换分解。计算从基准首阶段数量和各阶段转化率开始，按固定阶段顺序替换为当前值；每次替换造成的最终支付成功量变化记为该阶段的估算影响。贡献占比使用各阶段影响绝对值归一化。该方法可复核，但受替换顺序影响，因此属于近似归因。

维度贡献比较目标日与前 7 日同维度日均值，输出 Top 10 负向、Top 5 正向和 Others。交易诊断对主要城市进一步下钻设备与版本，最多处理前三个城市，避免组合爆炸。低样本分组会显示置信提示。

建议只由确定性规则触发，并必须引用 AnalysisEvidence。例如，支付成功率下降且版本维度集中时，建议复核版本支付链路，并给出验证指标。没有对应 evidence 的建议不能通过 AnalysisResultPackage 校验。

## 为什么不训练模型

当前需求不涉及需要从大规模语料学习的新能力。数据规模、结果协议、计算函数、表格输出和中文字号都应由可测试代码解决。用训练模型生成更丰富文字，无法补齐缺失的计算过程，还可能生成没有数据依据的结论。

## 未来语言能力的适用范围

未来可能在以下场景使用可选语言能力：

- 开放式问题理解。
- 非结构化文档检索。
- 指标同义词扩展。
- 对已有结构化结果进行自然语言润色。

即使未来增加这些能力，也不能绕过：

- Column Mapping。
- SemanticCatalog allowlist。
- QueryPlan 与计划审批。
- SQL Safety 与参数绑定。
- Reviewer。
- Evidence Chain。

语言解释只能使用已经计算并通过边界检查的结果，不能替代分析计算，也不能把相关性改写为因果关系。
