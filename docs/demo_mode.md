# 默认结果展示与演示入口

当前版本为 0.1.0，操作路径更新于 2026-10-08。主导航为“分析工作台、数据探索、分析方法、历史比较”，不提供旧版“简洁、专业、开发者”三模式切换。内部兼容值 `demo` 不是需要使用者选择的新模式。

## 阅读与操作顺序

1. 等待数据就绪，在分析工作台填写问题、核对实际配置和预检。高级参数与方案预览在“调整方法与参数”中；预览不计算，点击“开始分析”才提交。
2. 结果区上方先核对当前分析路径、源表、日期、筛选、方法和单位。指标诊断按“发生了什么 → 变化集中在哪里 → 证据支持到哪一步 → 下一步”阅读；其他方法保留自己的结果模板。
3. 通过“查看证据与明细”核对当前运行的真实表。结论页“生成 PDF 报告”先打开报告页，选择具体格式后才生成文件。
4. 城市当日探索可直接在结果旁“返回上一级分析”。父结果释放时先查看父摘要，点击“恢复该分析配置”，确认是否覆盖草稿，再经预检明确“重新运行该分析”。浏览、恢复与执行是三个动作。

## 质量与详情

五维质量摘要保持可见，严重失败单独显示。统计前提未验证不能因流程评分较高而视为已验证；完整口径与限制在“查看口径与质量”。

分析计划、执行记录、运行清单、血缘和观测数据收在“技术详情”，默认不显示原始 JSON。查看详情不重新分析，不预生成报告。审批仅对当前计划有效，恢复配置不能复用失效审批。

完整的三项演示见[演示脚本](demo_script.md)，当前日常操作见[使用手册](user_manual.md)。旧版截图和验收数字以各自日期为准，不代表本轮验证已通过。
