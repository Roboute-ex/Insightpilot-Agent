# 简洁演示模式

## 默认行为

界面模式默认值为 `demo`，页面首先展示数据概况和实际核心结果。分析方案放在结果之后的折叠详情中。

## 推荐顺序

1. 选择内置模拟数据和演示场景。
2. 保持分析目标为自动识别，或手动选择目标。
3. 从按类别组织的 6 个常用问题中一键填入，或输入自定义问题。
4. 点击“预览分析方案”只查看方法；点击“开始分析”执行实际计算。
5. 查看执行摘要、核心指标、异常、贡献、漏斗和建议。
6. 展开风险与限制并复核质量评分。
7. 按需准备中文报告导出，PDF 位于第一位。

## 默认隐藏

AnalysisPlan、WorkflowState、Trace、QueryPlan、JoinPlan、RunManifest、Lineage 和 Telemetry 原始 JSON 均不显示。

## 风险提示

高风险连接会暂停执行并显示中文说明。审批复选框默认不选中，批准只对当前计划编号生效。

普通限制只显示“当前分析包含 N 项风险与限制”，详细内容位于默认折叠区域。严重错误仍单独显示。

## 切换模式

需要查看完整步骤和查询摘要时切换“专业分析”；需要审计原始结构时切换“开发者模式”。切换不会清空最近一次结果。
