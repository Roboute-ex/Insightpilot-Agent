# v0.5 发布说明

## 版本目标

v0.5 将自定义数据流程升级为可复用分析工作台，重点是 Analysis Playbooks、Visual Diagnostics、Run Manifest 与内存导出。

## 更新亮点

- 七个内置分析 playbook 和确定性注册表推荐。
- ColumnMapping 驱动的 requirements 与参数验证。
- allowlist identifier、绑定标量和只读检查组成的安全 SQL template。
- JSON 可序列化 ChartSpec 与 Plotly 图表工厂。
- RunManifest、稳定数据指纹和 config import/export。
- Markdown、离线 HTML、Excel、Manifest JSON 和 ZIP Bundle。
- Streamlit playbook form、结果 tabs 和内存下载。
- CLI playbook、参数、config 和 export 参数。

## 新增文件

核心新增目录包括 `insightpilot/playbooks/`，以及 visualization specs/factory、manifest、HTML、Excel、bundle 模块和对应测试。

## 使用方式

```powershell
.\.venv\Scripts\python.exe examples/run_demo.py --list-playbooks
.\.venv\Scripts\python.exe examples/run_demo.py --scenario transaction --playbook periodic_summary --export-format markdown,html,excel,manifest,bundle
```

## 测试结果

已运行全量 `python -m pytest`：`124 passed, 1 warning in 81.55s`。warning 来自当前 Windows 环境无法创建 `.pytest_cache` 子路径，不影响功能测试结果。

## 当前限制

- 不使用在线 LLM，不提供自然语言 Text-to-SQL。
- 不保存上传文件或数据库结果。
- playbook 参数仅覆盖内置安全分析模式。
- HTML 图表为交互式离线内容，不强制静态图片导出。
- manifest 复现配置，不恢复原始数据。
