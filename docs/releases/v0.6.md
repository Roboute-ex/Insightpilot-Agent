# v0.6 发布说明

## 主题

v0.6 聚焦结果优先的中文体验、语义层、多表安全规划和本地质量治理，同时保留 v0.1-v0.5 的工作流、接入、剧本、图表和导出能力。本次变更是发布前完善，版本仍为 `0.6.0`，不创建第二个 v0.6 发布文件。

## 发布前完善

- 扩充交易、内容和直播内置模拟数据，支持 small、standard、large。
- 每个主要场景提供至少 12 个中文示例问题。
- 增加 AnalysisResultPackage、真实结果表、Evidence Chain 和证据绑定建议。
- 指标诊断增加多基准、漏斗顺序分解、维度贡献和受限二级下钻。
- 修复 legacy 自动工作流结果明细为空的问题。
- 紧凑摘要卡片标题调整为 12pt、正文调整为 10.5pt。
- 风险默认汇总折叠，运行性能进入专业详情，Evaluation 进入开发者区域。
- 增加中文 PDF，并将 PDF 放在六类下载第一位；ZIP 包含 `report.pdf`。
- 本次不涉及模型训练，也不使用生成式文字替代分析计算。

## 中文界面

- 默认使用简洁演示模式。
- 增加专业分析和开发者模式。
- AnalysisPlan 以中文摘要和步骤展示。
- 原始 JSON 只在开发者模式默认折叠展示。
- CLI 文本默认中文，JSON key 保持英文。

## 语义与多表

- 增加 SemanticCatalog、RelationshipGraph、JoinPlanner 和 MetricCompiler。
- 支持 simple、ratio、derived 和 cumulative 指标。
- 增加七表模拟数据、语义指标、漏斗和队列留存剧本。
- fanout 需要按 plan ID 审批，many-to-many 默认禁止。

## 质量治理

- 增加 Data Contracts、LineageGraph 和 LocalTracer。
- 增加 Core、Safety 和 Determinism 评估。
- CI 显式运行语义校验、全量测试、评估、中文 UI 冒烟和 JSON schema 检查。

## 可选预览

LangGraph 保持可选 fallback；OpenTelemetry 只做本地桥接预览；MCP preview 提供稳定英文工具 schema 和中文说明，不暴露任意 SQL，高风险执行要求明确授权并经过 Plan Review。

## 边界

本版本不接入在线模型，不要求密钥，不使用真实外部数据，不配置在线 exporter。所有示例和评估继续使用固定 seed 的模拟数据。

## v0.7 建议

后续可继续探索多表剧本组合、语义指标版本治理、本地评估基线比较和导出模板治理。
