## 打开与启动

已运行时直接打开，不另启实例：

~~~powershell
Start-Process 'http://127.0.0.1:8511/'
~~~

未运行时，在 PowerShell 使用现有环境：

~~~powershell
Set-Location 'D:\InsightPilot Agent\insightpilot-agent'
$env:PYTHONUTF8 = '1'
& .\.venv\Scripts\python.exe -m streamlit run app/ui_streamlit.py `
  --server.address 127.0.0.1 --server.port 8511 `
  --server.headless true --server.fileWatcherType none `
  --browser.gatherUsageStats false
~~~

服务终端持续运行正常；另开终端打开地址。确定停止才在服务终端按 Ctrl+C。刷新、关闭、释放或重启后不保证保留会话。

## 一次分析的主路径

数据来源 → 等待数据已就绪 → 分析工作台填写问题 → 核对推荐与口径 → 确认字段映射 → 应用参数并更新建议 → 开始分析 → 结论/明细 → 报告中生成、下载。

首次用“内置模拟数据 → 交易转化异常分析”，规模“标准”、种子 42，输入“昨日订单量为什么下降？”。演示“昨日”为固定数据参考日 2026-06-30，不是电脑昨天。接受推荐的实际按钮为“改用推荐方法”。

四导航：分析工作台提交问题；数据探索做单表描述性探索；分析方法查目录和配置；历史比较查看、恢复或比较其他运行。“更多示例”在问题输入旁，“调整方法与参数”在配置摘要下方；“开始分析”下方查看结果。“预览数据表”不改变真正的分析目标表。

结果旁先核对当前分析路径、源表、绝对日期、筛选、方法和统计单位。指标诊断按“发生了什么 → 变化集中在哪里 → 证据支持到哪一步 → 下一步”阅读；“查看证据与明细”进入当前运行的真实结果表。五维质量与严重风险一起核对，执行成功不等于统计前提已验证。

## 城市探索、返回与重跑

订单结论的城市表选择真实分组 → “查看该城市当日表现” → 核对父目标日与城市筛选 → 结果旁“返回上一级分析”。城市探索仅描述当日，不解释跨期下降原因。返回只查看父运行，不计算；根节点没有返回按钮。

从探索页返回时仍停留在探索页，保留尚未提交的参数；下方显示父运行范围。只有“确认恢复配置”才覆盖草稿并进入相应配置页，不能把切换主导航或刷新当成保存草稿。

父完整结果已释放时：父历史摘要 → “恢复该分析配置” → 阅读草稿覆盖提示 → 选择“保留当前草稿”或“确认恢复配置” → 完成预检 → 主按钮“重新运行该分析”。只有最后一步执行并产生新运行身份。恢复会清除旧审批，不自动补回明确清空的结果字段。

数据已变化须勾选“明确将该配置应用到当前数据并重新检查”，重新确认字段、口径与审批；所需源表不存在时须先加载。返回父摘要不能导出子报告，须有该选定运行的完整结果或明确标识的已生成文件。后台任务晚到不改变你已经选回的父分析。

## 十个方法怎么选

|方法|用途与必需输入|
|---|---|
|数据概览与质量检查|查缺失/重复；目标表|
|指标趋势分析|看变化；指标、至少两个有效日期|
|周期对比分析|比两期；指标、两窗口观测|
|维度贡献分析|静态分组/份额；指标、维度|
|实验组对照组比较|两组比较；指标、方向、独立单位|
|轻量因果探索|原始差/OLS调整；处理列、结果列、两组|
|周期分析摘要|时间概览；日期、指标|
|语义指标查询|受控多表；内置模型及配套表|
|漏斗转化分析|固定事件阶段；带时间的会话事件|
|队列留存分析|注册周回访；客户与会话表|

方法入口：主导航“分析方法”→“配置：方法名”。看“可用/待补充/与当前问题不匹配/当前数据不支持”；目录可见不等于能运行。

## 四个容易混淆的动作

- 接受推荐不计算；还需“开始分析”。
- 清空结果字段表示明确不选择，会阻断，不能期待自动补回。
- “生成”准备文件，“下载”才交给浏览器；结论页 PDF 按钮先打开报告页。
- 返回只切换查看，恢复只准备草稿，明确重跑才计算；最多 10 条小历史、一份完整结果。

## 因果、透视与保存

因果示例上传 causal_fixture.csv：目标选“轻量因果探索”；处理字段 group，结果/指标 outcome；映射“协变量”和参数“控制变量”均选 covariate；确认映射；处理值 treatment、对照值 control；应用参数后开始。未筛选时原始差 2、调整 2、n=24。运行成功不证明因果。

透视用 pivot_fixture.csv：指标 amount，行 row_group，列 column_group。求和 120，均值 30；甲/乙均值 20/40。分子 numerator、分母 denominator 的加权比率为 10/92，不能平均逐行比率；乙零分母未定义。entity_id 全范围去重 3，不能把两组各 2 相加。20% 到 25% 是增加 5 个百分点。

探索先勾选确认再“生成探索结果”；换图型只改展示，换聚合/范围须重新生成。报告绑定所选成功运行，不读取未提交草稿。PDF、Markdown、HTML、Excel、运行清单 JSON、ZIP 均按需生成；下载目录由浏览器决定。JSON 不代替数据备份或审批。

## 三个常见卡点

|现象|先做什么|
|---|---|
|端口不可用|先打开已有服务；需要时另选空闲端口|
|开始分析不可用|读缺口，确认真实列、组值、单位和口径|
|旧结果或下载没更新|应用参数并重跑；核对所选运行，再生成并下载|

不要用清缓存、重启或结束全部 Python 作为第一步。完整步骤见[使用手册](user_manual.md)。
