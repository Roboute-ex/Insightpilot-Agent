# 统一工作台与旧界面迁移

适用版本：0.1.0。实现核对日期：2026-09-29。

## 默认页面

首页使用一个工作台：数据摘要、一个问题输入框、三个适配示例与“更多示例”、一个建议摘要及当前状态、一个“开始分析”主按钮。侧边栏保留数据来源和场景，规模与种子位于“数据设置”；预览移到“查看数据”。

首页不再显示“简洁演示/专业分析/开发者模式”切换。内部 `ViewMode`、兼容字段、CLI与运行记录仍保留；技术能力通过按需入口访问，没有删掉审计记录。标题12pt、正文10.5pt，中文控件占位文案不以缩小字号代替简化。

|入口|可以做什么|
|---|---|
|调整方法与参数|设置分析目标、规则/LangGraph后端、手动方法、字段映射和强制重算。只有当前方法需要时才显示组值、控制变量等。|
|查看全部分析方法|首页与调整入口并列；按注册表完整展示十个剧本。每项显示中文名称、用途、可用/待补充/与当前问题不匹配/当前数据不支持、基本要求和缺口，并有直接配置按钮。选中不适用方法仍不能执行。原自动工作流仍保留在高级方法选择器中。|
|查看分析方案|二级方案预览；不与开始按钮并列争夺主流程，也不因此执行统计。|
|结论 / 图表 / 明细 / 报告|成功运行后的主要结果导航；只构建当前选中页，明细保留分页。|
|查看口径与质量|复核指标口径和执行、口径确认、数据质量、统计前提、证据完整度五维。流程评分不是结论百分之百正确。|
|技术详情|按需访问方案、SQL、血缘、调试数据、性能与评估工具；默认关闭时不构建大型展示对象。|
|继续分析 / 历史对比|放在结果后，默认收起。继续、恢复、返回上一步、修改维度/基准及比较两次运行仍可用。|

## 操作时序

问题在参数表单外；按 Enter 或失焦可更新轻量建议，不会自动计算。参数表单中的新值只有点击“应用参数并更新建议”才生效。修复建议或应用参数后，需要再次明确点击主“开始分析”。

显式手动方法在主摘要始终可见，收起高级面板不会使它成为隐形配置。点击示例会清理不适用的旧方法参数并恢复自动推荐。仅预览另一张表不会改变分析范围；真正目标表必须在字段映射入口明确选择。

缺输入的原因与修复按钮直接显示在开始按钮附近，标为“待补充信息”，不再用“当前任务失败”代替配置说明。任务实际异常仍保留脱敏具体原因。推荐就绪不是SQL授权或统计前提证明。

## 结果、历史和资源

切页、展开高级设置、查看建议不重新分析或完整哈希。原始数据、完整结果、历史摘要和导出继续使用原有会话预算与后台并发限制；没有增加无隔离全局数据缓存或磁盘数据缓存。

历史只保存不可变配置、有限摘要和受控结果引用，最多10条小历史，完整大结果继续服从现有缓存。被释放的历史显示需要重新执行；查看配置不伪造已有完整结果。恢复历史会重新检查数据版本，不恢复旧审批。分支比较检查口径、单位、数据版本、时间范围和方法等，运行差异不冒充显著性或因果效果。

“报告”首先提供PDF，另外保留Markdown、HTML、Excel、运行清单和ZIP。各格式延迟生成并绑定所选成功运行的 `run_id`；未应用参数、新问题或新建议不会混入旧报告。生成ZIP时按包内容需要生成相关报告。结果释放或运行未成功时，不能导出假成功报告。

后台取消是协作式取消：当前不可中断原生步骤结束后才能释放其引用。界面显示取消请求，不声称工作线程立刻停止。数据、请求或分支变更仍使用原有归属检查拒绝晚到结果。

## 测试解释

旧三模式首页测试迁移为默认页、高级入口和技术详情的展示契约；原数值、安全、证据和可用能力检查继续保留。

本机Streamlit 1.63的AppTest将Expander视作Block，没有原生点击方法，默认也不把其布尔打开状态加入WidgetStates。`tests/ui_expander_support.py` 仅在测试中补传已有打开/关闭布尔状态；它不点击分析按钮、不修改分析请求、不替代预检。相关测试据此验证开、重跑保持、关闭以及惰性构建，但不能据此声称已做浏览器鼠标点击。

AppTest交互、真实浏览器原生展开/点击与视觉检查、health=200分别记录。健康接口只能证明服务响应，不能证明方法匹配、页面操作或统计正确。本文说明实现与操作契约，不代替最终验收记录；实际结果见 [guided_analysis_acceptance.md](guided_analysis_acceptance.md)。

本次补充的方法目录入口、有效与无效因果输入及真实浏览器记录见 [method_discovery_acceptance.md](method_discovery_acceptance.md)。
