# 主任务人工观察记录模板

适用版本：0.1.0；模板日期：2026-10-08。当前尚未开展真人试用，以下均待实际使用者执行。自动测试、浏览器脚本、截图与健康响应不能填写为独立完成人数、满意度或节省时间。

使用内置模拟数据或[现有教学小样](examples/user_manual/README.md)，不收集私人业务数据。征得同意后记录匿名编号和观察笔记；未经同意不录屏。可邀请 2–3 位具备基础数据分析知识的使用者作探索性观察，用户本人试用单列，不据此声称统计代表性。

## 三项任务

|任务|交给使用者的目标|观察要点|
|---|---|---|
|A 指标与范围|使用合成运营表完成一次指标比较，说明所用日期、指标与当前范围。|是否找到配置与开始入口；能否复述统计单位、基准和必要限制；是否把电脑日期当数据日期。|
|B 分组与返回|进入一个有效城市查看当日表现，再回到整体分析；若父结果已释放，恢复并重新运行，然后保存所选运行的报告。|是否发现结果旁返回；是否分清父摘要与完整结果、保留草稿与覆盖、恢复与执行；报告是否为目标运行。|
|C 澄清与阻断|面对两个可用转化率定义，说明需要哪一个并完成确认；遇到不支持的配置时说明为什么尚不能得到结论。|是否理解分子分母；是否误把画像当因果回答；是否理解缺字段、待澄清与成功的区别。|

任务 C 可使用[演示脚本](demo_script.md)的四行率小样。观察者先给任务目标，不预先讲具体点击路径；确需帮助时记录发生时间与内容，不把帮助后的完成记为独立完成。
