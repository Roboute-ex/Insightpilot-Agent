# 核心恢复审计与本次验证

本文件记录从原仓库恢复的核心模块及本次修复，不引用历史测试总数作为成绩。所有修改仅在工作项目完成；source-original 基线未修改。

## 必须保留的边界

- 跨事实预聚合已支持整体或共同非时间维度的 simple/ratio/derived：每个事实单独经安全多对一/一对一维度连接聚合，然后全外合并同粒度结果；单侧缺失的sum/count为0，零分母为null。跨事实日期/累计尚无统一时间轴，事实专属维度和扇出维度仍明确拒绝。目录新增每会话金额；手算70金额/5会话=14，按城市A=30/3=10、B=40/0不可计算、C=0/2=0，增加100条订单项不增额，过滤、排序和完整工作流请求实测通过。
- 外部 PostgreSQL/MySQL 连接代码有只读事务和超时控制，但本轮没有连接真实外部数据库，驱动/服务端差异需单独验收。SQLite 已实测；应用检查不能替代数据库最小只读权限。
- 语义审批是本地只读计划审批，并非访问控制服务或签名认证协议。只有当前编译器生成且通过绑定检查的对象可执行。
- 用户级连续结果重复事件的默认合并口径为用户均值；业务须确认随机化单位和结果口径。没有单位字段会明确标注独立性未确认。稀疏二元数据的 Wald 近似会有警告，本版不宣称精确检验。
- 活跃用户来自支付明细，只能表述支付活跃用户；原始流量旅程计数没有全站UV实体记录。主播开播场次、观众会话和去重观众使用不同ID，不混算。
- 关联分析为会话层级描述性结果；设备×网络均值不等同于个体因果效应。
- 源码快照、wheel、最终全量 pytest、PDF/UI 视觉验收由项目主验收日志记录；本审计不将未执行检查写成通过。
