# 用户手册教学数据

这两份 CSV 原样复制自 2026-09-30 的最终浏览器验收目录 `reports/workbench/browser-final-all-20260930-114015987/`，由 `scripts/check_workbench_browser.py` 生成。数据全部合成，可用于手册操作练习，不含真实业务或个人记录。使用 UTF-8、逗号分隔、第一行为字段名；两份文件都保留了原始字节和字段名。

## causal_fixture.csv

一行是一条合成观测，共 24 行；`control`、`treatment` 各 12 行。日期范围为 2026-09-01 至 2026-09-12。这里的 24 行是教学规模，不是生产样本量建议；没有提供独立实体 ID，也不能据此确认独立性或随机化。

| 字段 | 含义与配置 |
| --- | --- |
| `date` | ISO 日期；日期字段选择此列。 |
| `group` | 处理字段；列的取值为 `control` 和 `treatment`。这两个组值不是字段名。 |
| `outcome` | 数值结果，单位为教学示例的原始数值单位；指标字段和结果字段选择此列，聚合方式选择均值。 |
| `covariate` | 数值协变量，每组均为 0 至 11；字段映射中的协变量和方法参数中的控制变量均选择此列。 |

因果示例设置：处理组值 `treatment`，对照组值 `control`。对照组均值 15.5，处理组均值 17.5，所以原始组间差为 2。用截距、处理组指示变量和 `covariate` 对 `outcome` 做普通最小二乘回归，处理组系数为 2，有效样本量为 24。文档任务使用 NumPy 独立重算，并与现有浏览器验收记录核对一致。

这份示例只支持说明原始差和 OLS 调整结果的读取方式。字段齐全与成功运行不证明随机化、无未观测混杂、重叠性或因果识别前提，不包含倾向评分加权结果。

## pivot_fixture.csv

一行是一条合成观测，共 4 行；`entity_id` 为 `u1` 的实体跨组出现，因此不能将各组去重数相加作为整体去重数。

| 字段 | 含义与配置 |
| --- | --- |
| `row_group` | 透视行维度，取值为甲、乙。 |
| `column_group` | 透视列维度，取值为 X、Y。 |
| `amount` | 数值指标；用于合计与均值，单位为教学示例的原始数值单位。 |
| `entity_id` | 去重对象，取值为 u1、u2、u3；去重计数时选择此列，不能将编号当作连续数值指标。 |
| `numerator` | 加权比率的分子字段；比率示例中指标字段也选择此列。 |
| `denominator` | 加权比率的分母字段。 |

| 口径 | 整体 | 甲组 | 乙组 |
| --- | --- | --- | --- |
| `amount` 合计 | 120 | 40 | 80 |
| `amount` 均值 | 30 | 20 | 40 |
| `entity_id` 去重计数 | 3 | 2 | 2 |
| 加权比率 | 10/92，约 0.108696 | 10/92，约 0.108696 | 0/0，不可计算，显示为缺失 |

甲组比率为 `(9+1)/(90+2)=10/92`，约 10.8696%；不是 `(9/90+1/2)/2=0.3`。整体重算分子与分母后也是 10/92；乙组零分母不能解释为 0%。整体去重为 `{u1,u2,u3}` 共 3 个，不是两组去重数之和 4，也不是其它测试数据中的 2。

行、列和总计应在各自对应的原始范围重新聚合。文档任务离线重算了整体、两个行组和两个列组的合计、均值、比率与去重数，并与该目录的实际返回记录逐项一致。
